# Agentes de IA

Colección de agentes de IA en Python para automatizar tareas de desarrollo.

| Agente | Qué hace |
|---|---|
| [`agente_html`](./agente_html) | Genera páginas web HTML modernas a partir de una descripción en lenguaje natural. El comportamiento del agente se define con *skills* en Markdown (estructura, estilos, componentes, animaciones, responsive y SEO) y aplica correcciones automáticas al HTML generado. Funciona con Ollama (local), OpenAI, Anthropic o NVIDIA NIM. |

Cada agente tiene su propio README con requisitos e instrucciones de uso.
